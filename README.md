# Salary Compass

Create a modern, responsive Salary & Currency Dashboard web application.

Main features:

Salary Tax Calculator

 Enter annual salary

 Select a country

 Calculate estimated tax, gross salary, net salary, monthly salary, and weekly salary

 Show the tax rate with a progress bar

 Display results in a clean table

Country Comparison

 Compare the selected country with another country

 Show tax rates, taxes, and net salaries

 Display a simple comparison chart

Currency Converter

 Enter an amount

 Select “From” and “To” currencies

 Convert instantly

 Support TND, EUR, USD, GBP, CAD, CHF, JPY, and AUD

 Use approximate exchange rates

Design:

 Modern professional financial dashboard

 Clean white cards with rounded corners

 Blue/green gradient buttons

 Centered layout

 Two main cards side-by-side on desktop

 Stack cards vertically on mobile

 Responsive design using Flexbox

 Add charts for salary breakdown and country tax comparison

 Include a Download CSV button

 Include a Reset button

 Use clear icons and typography

 Make the interface visually polished and easy to use

Use realistic sample tax rates and currency exchange rates, and clearly indicate that they are approximate.
